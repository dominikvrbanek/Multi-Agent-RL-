# experiments/

One short file per meaningful training run (e.g. `2026-11-20-ppo-baseline.md`):

- Config used (link to the file in the repo or paste the key hyperparameters)
- Key results (reward curve summary, win rate vs baseline)
- W&B run link
- One-line takeaway

Raw logs and model files do not belong here. The narrative "what we tried and why" goes in `docs/experiment-log.md`.
